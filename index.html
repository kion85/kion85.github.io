🚀 k85OS — Custom Firmware

Custom firmware for M5Stack-family devices (ESP32-S3), written in C/C++ on ESP-IDF v5.3.1. Originally ported from an earlier MicroPython/UIFlow prototype into a modular ESP-IDF C++ codebase.

🎯 Supported Targets

ESP32-S3 (tested on ESP32-S3-PICO-1-N8R8, 8MB Flash + 8MB Octal PSRAM)

✨ Features

  • Store (games): Puzzle (2048, Tetris), Arcade (Snake, Memory Match), Classic (Reaction test, Flappy, Balance), Pong
  • Standalone apps: Cube (3D wireframe demo), Colors, Clock (NTP-aware with uptime fallback)
  • Tools: WiFi Connect / Manager (3 saved networks), Terminal (Free RAM, Uptime, Reboot), Bluetooth Scan, I2C Scanner, GPIO Control, Files browser, Music Player, Melodies, Mic Test, Air Mouse (IMU cursor), Hotspot, Calculator
  • Settings: Theme, battery mode, brightness, volume, boot style, cursor mode (IMU pointer), Desktop/OS mode (desktop + taskbar)

🎨 Theming (.thm files)

UEFI/BIOS themes are plain-text .thm files (single line, fields separated by |):

Name|Background|Text|Accent|Dark|Icon

📂 Project Structure

├── CMakeLists.txt ├── partitions.csv ├── sdkconfig.defaults └── main ├── CMakeLists.txt ├── k85os_idf.cpp # entry point ├── core/ # config, theme, input, power, boot, rtc/ntp ├── ui/ # menu, list_menu, settings_menu ├── net/ # wifi ├── apps/ # games & tools └── system/, steps/

🛠️ Build

Requires ESP-IDF v5.3.1.

idf.py set-target esp32s3 idf.py build idf.py -p COM_PORT flash idf.py -p COM_PORT monitor

💬 FAQ & Notes

"Why doesn't this firmware have features like Bruce? I don't have any real desire for my firmware to be able to attack anyone, capture handshakes, and so on. What I actually want is for these sticks to have something like a PC-style OS... packed into a tiny microcontroller. Good luck to everyone, and I wish you all the very best in life!"

⚠️ Очистка памяти устройства

Консоль idf.py monitor с поддержкой цветных логов и Reset по DTR/RTS.
