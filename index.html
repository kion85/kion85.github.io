Полный образ прошивается на 0x0. OTA-слоты используются для обновления прошивки без затирания загрузчика.

💡 Доступные системные команды (введите в строку ниже и нажмите Enter):

О k85OS

Custom firmware for M5Stack-family devices (ESP32-S3), written in C/C++ on ESP-IDF v5.3.1.

✨

Возможности

Что входит в прошивку

  • ✔Store (игры): Puzzle (2048, Tetris), Arcade (Snake, Memory Match), Classic (Reaction, Flappy, Balance), Pong
  • ✔Отдельные приложения: Cube (3D wireframe), Colors, Clock (NTP-aware with uptime fallback)
  • ✔Инструменты: WiFi Manager (3 сети), Terminal, Bluetooth Scan, I2C Scanner, GPIO Control, Files, Music Player, Melodies, Mic Test, Air Mouse (IMU), Hotspot, Calculator
  • ✔Настройки: тема, батарея, яркость, громкость, стиль загрузки, курсор (IMU), Desktop/OS mode
  • ✔Темы (.thm): plain-text, поля через | → Name|Background|Text|Accent|Dark|Icon
🛠️

Сборка из исходников

Требуется ESP-IDF v5.3.1

idf.py set-target esp32s3 idf.py build idf.py -p COM_PORT flash idf.py -p COM_PORT monitor
